# mustanad · مُستَنَد

[English](README.md)

**اسأل عن مستنداتك أنت، واحصل على إجابة مع المقطع الذي جاءت منه — بالعربية أو الإنجليزية، على
جهازك، ودون أي مفتاح API.**

## المشكلة التي يحلّها

دليل الموظفين، سياسة الاسترجاع، اتفاقية الدعم: المعلومة موجودة لكن لا أحد يجدها. وأغلب أدوات
«اسأل مستنداتك» ترسل ملفاتك إلى خدمة خارجية وتجيب دون أن تذكر المصدر. mustanad يعمل محليًا
ويُرفق بكل إجابة المقطع الذي استند إليه، لتتحقق منه بنفسك.

## ما الذي يقدّمه

- فهرسة ملفات PDF و DOCX والنصوص، وتخزينها في SQLite.
- استرجاع BM25 مكتوب من الصفر، مع تطبيع وتجذيع خفيف للعربية.
- إجابة استخراجية تعمل دون اتصال، مع الاستشهاد بالمصدر (رقم الصفحة في PDF).
- مزوّد خارجي اختياري (ollama أو openai) لمن يريد صياغة توليدية.
- واجهة سطر أوامر وواجهة HTTP بمفتاح API وحدّ لعدد الطلبات.

## التشغيل السريع

```bash
make setup
make demo
```

لا يحتاج مفتاح API ولا شبكة ولا تنزيل نموذج: يفهرس أربعة مستندات تجريبية (اثنان بالعربية واثنان
بالإنجليزية) ثم يطرح عليها أسئلة باللغتين.

## الجودة

238 اختبارًا آليًا، مع ruff و mypy نظيفين، و CI على كل دفع.

## الحدود، بصراحة

- مشروع محفظة أعمال: لا مستخدمون في بيئة إنتاج.
- جموع التكسير لا تتطابق (مثل «يوم» و«أيام»)، لأن التجذيع خفيف ودون قاموس.
- المزوّد الاستخراجي يقتبس ولا يلخّص: لا يدمج مقطعين في إجابة واحدة.
- لا يوجد OCR: ملفات PDF الممسوحة ضوئيًا تُرفض برسالة واضحة.
- الاسترجاع لفظي افتراضيًا: سؤال لا يشارك المستند أي مفردة لن يجد شيئًا.
- مستأجر واحد: كل مفتاح API يرى كل المستندات.

التفاصيل الكاملة في [README الإنجليزي](README.md).
